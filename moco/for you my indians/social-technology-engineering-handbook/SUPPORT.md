# Learning Support

## How to get the most out of the handbook

1. Start with [`QUESTION.md`](QUESTION.md) and choose one question.
2. Follow the chapter links listed under that question.
3. Search the chapter for the exact term or heading you do not understand.
4. Use the [Hinglish glossary](handbook/HINDI_GLOSSARY_AND_STUDY_GUIDE.md) for terminology.
5. Draw the system, build a small lab and write down what you observed.

## Asking a question

Use GitHub Discussions if the repository owner enables them. Use GitHub Issues for factual corrections, broken links or missing explanations, following [`CONTRIBUTING.md`](CONTRIBUTING.md).

Please include:

- the chapter filename and section;
- what you expected to understand;
- what part is unclear;
- what you have tried;
- a source link if your question is about a changing fact or current version.

Do not post passwords, access tokens, personal data or confidential information.

No response time or personal support service is guaranteed. This is a public learning resource maintained as time permits.
