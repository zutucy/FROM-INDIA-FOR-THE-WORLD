# Security and Responsible Reporting

This repository is primarily an educational documentation project. It does not operate the example systems described in the handbook and does not provide a production application or security service.

## Found a risky or misleading security explanation?

- Open an issue naming the chapter and heading.
- Explain the risk at a high level and provide authoritative references where possible.
- Suggest a safe correction or defensive clarification.
- Do not include live credentials, personal data, private keys, tokens or sensitive system details.

## Found a vulnerability in a third-party system?

Do not test systems without explicit authorization. Follow the affected provider's published vulnerability disclosure or bug-bounty process. Do not use this handbook's issue tracker to publish an unpatched vulnerability or exploit instructions against a real target.

## Scope and limitations

A security statement in this handbook is educational guidance, not a guarantee. Real systems require a product-specific threat model, code review, authorised testing, remediation, monitoring and incident-response ownership.
